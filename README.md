# Rohit — Portfolio Website

A responsive portfolio for a second-year B.Tech student, built with plain HTML, CSS, and JavaScript.

## Open locally

Open `index.html` in a modern browser. The portfolio and FAQ work locally. The weather lookup needs an internet connection and uses the public Open-Meteo geocoding and forecast APIs.

## Included

- Responsive portfolio sections for introduction, projects, skills, and contact
- CSS-built project illustrations, with no image downloads required
- City weather lookup without a client-side API key
- Local portfolio FAQ experiment
- Interactive prompt workshop that turns a rough task into a structured prompt
- Accessible navigation, status announcements, keyboard support, and reduced-motion handling

The project descriptions and student details are based on the supplied project files. Add verified repository links, a real contact address, and any further personal details before publishing.
